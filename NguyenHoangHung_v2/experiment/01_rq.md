# Research Question – LLM for Unit Test Case Generation

**Thành viên:** Nguyễn Hùng (SE180765)

---

## RQ chính thức

"Đối với các class Java và Python có Cyclomatic Complexity từ 5–15, liệu GPT-4o mini sử dụng Zero-shot prompting có đạt Mutation Score ≥ 40% và Branch Coverage ≥ 50%, đồng thời duy trì Compilation Success Rate ≥ 80%, khi so sánh với Randoop và student-written tests hay không?"

## PICO

- **P (Population):** Java/Python functions với cyclomatic complexity từ 5–15
- **I (Intervention):** GPT-4o mini zero-shot
- **C (Comparison):** Student-written tests và Randoop
- **O (Outcome):** Branch coverage ≥50% và mutation score ≥40% và compilation success rate ≥ 80%
